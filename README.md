# UAT Test Project

Bu projede basit bir online başvuru sistemi üzerinden test ve kullanıcı kabul süreçlerini analiz ettim.

## Proje Amacı

Gereksinimlerden başlayarak test senaryoları, test case'leri ve UAT sürecini oluşturdum. Ayrıca gereksinimlerin testlerle bağlantısını göstermek için Requirements Traceability Matrix hazırladım.

## Proje Akışı

Başvuru Formu → Bilgi Kontrolü → Başvuru Oluşturma → Başvuru Değerlendirme → Onay / Red

## Kapsam

Bu projede;

* Gereksinimleri belirledim.
* Test senaryoları oluşturdum.
* Test case'leri hazırladım.
* Anonim test verileri kullandım.
* UAT planı ve senaryoları oluşturdum.
* UAT sonuçlarını kayıt altına aldım.
* Gereksinim ve test ilişkisini RTM ile gösterdim.

## Önemli Not

Bu çalışma **portföy amacıyla hazırlanmış bir simülasyondur**. Gerçek bir ürün veya şirket sistemi üzerinde gerçekleştirilmiş bir test çalışması değildir.

Test sonuçları ve UAT sonuçları, oluşturduğum senaryolar üzerinden simüle edilmiştir.

Projede gerçek kişi, şirket veya kişisel veri kullanılmamıştır.
