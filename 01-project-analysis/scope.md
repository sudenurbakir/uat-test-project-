# Project Scope

## Kapsam

Bu projede online başvuru sürecinin test ve kullanıcı kabulü açısından analizini yaptım.

### Dahil Olanlar

* Başvuru formunun doldurulması
* Zorunlu alanların kontrolü
* Başvurunun oluşturulması
* Başvuru bilgilerinin görüntülenmesi
* Başvuru durumunun güncellenmesi
* Başvurunun onaylanması veya reddedilmesi
* Test senaryoları
* UAT senaryoları

### Dahil Olmayanlar

* Ödeme işlemleri
* Belge doğrulama
* E-posta / SMS gönderimi
* Kullanıcı yetkilendirme sistemi
* Gerçek sistem geliştirme

## Başvuru Akışı

```text 
Başvuru Formu
      ↓
Bilgi Kontrolü
      ↓
Başvuru Oluşturma
      ↓
Değerlendirme
      ↓
Onay / Red
```

## Başarı Kriteri

Başvuru sürecindeki temel işlemlerin gereksinimlere uygun çalışması ve kullanıcı tarafından kabul edilebilir olması hedeflenmiştir.
